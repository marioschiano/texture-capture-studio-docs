# Texture Capture Studio Documentation

Official bilingual documentation for the **Texture Capture Studio** Blender add-on.

- English documentation: `docs/`
- Documentazione italiana: `docs/it/`
- Site generator: MkDocs Material + `mkdocs-static-i18n`

## Local preview

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

The documentation site is configured for:
