# Changelog

## 0.3.20

- Rebuilds atlas layouts from individual connected UV islands.
- Adds optional 90-degree island rotation during automatic pixel-perfect packing.
- Preserves original texel density and exact pixel footprint without scaling or distortion.
- Creates a dedicated Atlas collection with independent mesh and material copies.
- Consolidates copied assets onto one shared atlas material and texture.
- Optionally bakes Base Color after packing.
