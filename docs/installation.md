# Installation

Texture Capture Studio is distributed as an installable Blender Extension ZIP.

## Requirements

- Blender 4.2 or later.
- The Texture Capture Studio ZIP file. Do not extract the ZIP before installation.

## Install the extension

1. Open Blender.
2. Go to **Edit → Preferences → Get Extensions**.
3. Open the menu in the upper-right corner and choose **Install from Disk**.
4. Select the Texture Capture Studio ZIP.
5. Confirm the installation and enable the extension if Blender asks.
6. In the 3D View, press `N` and open the **Texture Capture** tab.

The panel title shows the installed version, for example **Texture Capture Studio v0.3.20**.

## Update

Install the newer ZIP from disk. If Blender keeps an older build active, remove the previous extension, restart Blender, and install the new ZIP again.

!!! tip
    Check the version shown in the horizontal panel title before testing a new build.
