# Installazione

Texture Capture Studio viene distribuito come Blender Extension installabile in formato ZIP.

## Requisiti

- Blender 4.2 o successivo.
- Il file ZIP di Texture Capture Studio. Non estrarre lo ZIP prima dell'installazione.

## Installare l'estensione

1. Apri Blender.
2. Vai in **Edit → Preferences → Get Extensions**.
3. Apri il menu in alto a destra e scegli **Install from Disk**.
4. Seleziona lo ZIP di Texture Capture Studio.
5. Conferma l'installazione e attiva l'estensione se Blender lo richiede.
6. Nella 3D View premi `N` e apri la scheda **Texture Capture Studio**.

Nel titolo del pannello viene mostrata la versione installata, per esempio **Texture Capture Studio v0.3.128**. Questa guida fa riferimento alla versione 0.3.128.

## Aggiornamento

Installa da disco lo ZIP più recente. Se Blender continua a caricare una build precedente, rimuovi la vecchia estensione, riavvia Blender e installa nuovamente il nuovo ZIP.

!!! tip
    Prima di provare una nuova build, controlla sempre il numero di versione scritto nel titolo orizzontale del pannello.
