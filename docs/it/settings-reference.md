# Riferimento impostazioni

Una consultazione rapida dei controlli principali. Per le schermate e la spiegazione completa delle opzioni nella sidebar consulta [Impostazioni avanzate](advanced-settings.md) e [Workflow completo](workflow.md).

## Foto e prospettiva

| Impostazione | A cosa serve |
| --- | --- |
| **Load Photo** | Carica la fotografia sorgente. |
| **Lock Camera View** | Attiva la vista di lavoro sulla foto; disattivalo per navigare normalmente. |
| **Perspective Mode** | Sceglie una ricostruzione a due o tre punti di fuga. |
| **Sensor Width (mm)** | Converte la focale stimata in millimetri; non regola la velocità del mouse. |
| **Guide Thickness / Guide Label Size** | Regolano spessore ed etichette delle guide. |
| **Auto Guide Sensitivity** | Controlla la sensibilità del rilevamento automatico delle guide. |

## Cattura e ritocco

| Impostazione | A cosa serve |
| --- | --- |
| **New Points / Edit Points** | Creano una selezione o permettono di modificarne i punti. |
| **Aligned Rectangle** | Definisce un rettangolo allineato alla foto con due angoli. |
| **Extraction Method** | Sceglie correzione prospettica, proiezione tessellata o Camera Projected. |
| **Target UV Ratio** | Sceglie come determinare le proporzioni del risultato. |
| **New Points Surface** | Seleziona la foto 2D o una superficie prospettica per i nuovi punti. |
| **Output Folder / Texture Name** | Impostano destinazione e nome base delle texture. |
| **Clean Lighting** | Stima una correzione delle variazioni di luce su una nuova copia. |
| **Advanced Retouch** | Apre una copia nell'Image Editor per il ritocco con il timbro Clone. |

## Visualizzazione e precisione

| Impostazione | A cosa serve |
| --- | --- |
| **Show Vertex Dots / Vertex Dot Color / Dot Opacity** | Controllano visibilità, colore e opacità dei punti. |
| **Dot Size Mode / Vertex Dot Size / World Dot Size** | Scegli e regoli la dimensione dei punti nello schermo o nel mondo 3D. |
| **Polygon Fill Color / Polygon Fill Opacity** | Controllano colore e trasparenza del riempimento. |
| **Selected Polygon Opacity** | Evidenzia il riempimento del poligono selezionato. |
| **Perspective Guide Opacity** | Regola l'opacità delle guide colorate. |
| **Show 3D Cursor / Automatic Edit Points** | Gestiscono cursore 3D e modifica diretta dei punti. |
| **Vertex / Edge / Guide Snapping** | Abilitano i diversi agganci; le distanze sono regolabili in pixel. |
| **Precision Magnifier** | Ingrandisce la zona del cursore; offre zoom, rallentamento, dimensione, mirino e griglia. |

## Seamless, Trim e Atlas

| Impostazione | A cosa serve |
| --- | --- |
| **Edge Blend Width** | Regola la zona di sfumatura per il seamless. |
| **Horizontal Bands · Full Width 0–1** | Compone fasce orizzontali che attraversano tutto lo spazio U. |
| **Make Seamless X / Seamless Method** | Attivano e scelgono la sfumatura orizzontale delle fasce. |
| **Sheet Width / Trim Padding** | Regolano larghezza e margini della trim. |
| **Atlas Padding / Maximum Atlas Size** | Regolano margini e limite di dimensione dell'atlas automatico. |
| **Allow 90° Rotation** | Consente la rotazione delle isole complete durante il packing. |

Per i controlli e i limiti della generazione PBR consulta [Mappe PBR e displacement](pbr-maps.md); per i formati consulta [Consigli export](export-tips.md).
