# Documentation draft checklist

The bilingual structure and first-pass text are ready for review.

## Before the public launch

- Add a hero image showing the complete Texture Capture Studio panel.
- Add screenshots for Source Photo, Perspective Match, point placement, PBR generation, displacement, Trim Sheet, Atlas, Export, and Advanced.
- Add a short GIF showing the Precision Magnifier during point placement.
- Confirm the final public add-on version and Blender compatibility.
- Add troubleshooting, FAQ, video tutorials, support contact, and a full settings reference.
- Review English terminology against the final Blender UI labels.
- Review the Italian copy after the workflow and button labels are frozen.

## Publishing

1. Create the public GitHub repository `marioschiano/texture-capture-studio-docs`.
2. Push this project to its `main` branch.
3. In repository settings, configure GitHub Pages to use **GitHub Actions**.
4. The included workflow builds both `/` (English) and `/it/` (Italian).
